# Ankicard 0.4.1

新建英语、日语 AI 检索任务使用 DeepSeek Flash 和内置提示词时，启用 W7 制卡流程。首轮在本地构造查询，筛掉检索列表和重复资料，缺少匹配词典时按需补搜。正文和标签复核共用紧凑目录，局部排版优先使用原文短语，保留来源标记、例句和标签验收。

自动配图会过滤文档封面缩略图。对于示意图，候选需有图解特征或匹配的语境线索，以减少仅凭同名选错对象的情况。真人发音继续走应用原有词典来源。

下载 **Ankicard-0.4.1-windows-x64-Setup.exe** 进行覆盖升级。已保存的任务按原提示词和标签快照继续。使用自定义提示词或其他生成模式的任务走原有制卡流程。

## English

W7 reduces repeated generation and curates live dictionary evidence for new English and Japanese AI-search jobs using DeepSeek Flash and the bundled prompts. The release adds image guards for document covers and diagrams selected only through an ambiguous title match. Existing jobs retain their saved configuration and progress.

The installer includes the application and WebView2 deployment component. Verify the installer against the attached SHA-256 checksum.
