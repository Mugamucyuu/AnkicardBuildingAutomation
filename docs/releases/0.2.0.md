Windows 本地安装版现已提供，保留当前界面及制卡、批量导入、提示词管理和标签功能。

下载 **Ankicard-0.2.0-windows-x64-Setup.exe**，双击安装，从桌面或开始菜单打开 Ankicard。无需安装 Python、配置环境或手动访问 localhost。安装包包含完整的 WebView2 运行时安装组件，缺少时自动安装，因此下载体积约 220 MB。

- 支持 Windows 10 1809+ / Windows 11 x64。
- 生成仍需模型 API key、网络和额度；导入仍需桌面 Anki 与 AnkiConnect。
- 更新前先关闭应用，再运行新版安装包。用户数据在更新和卸载时保留。
- 安装包与应用尚未签名，Windows 可能提示未知发布者。可用附带的 SHA256SUMS.txt 校验下载文件。
- 内部服务仅监听本机、自动选择端口并随窗口退出；异常中断的任务沿用已有恢复机制。

Also includes the latest local functionality: bounded word concurrency, batch Anki import, prompt transparency/validation controls and improved image selection.

Validation covers the core suite, real frozen WebView2 window, three-language offline generation, startup/shutdown, install/reinstall/uninstall and preserved user data. Test runs exclude paid model calls and the user's real Anki collection. A machine with no WebView2 installed still needs separate clean-VM verification before broad distribution.

Build instructions, dependency license notices and limitations are documented in [the Windows guide](https://github.com/Mugamucyuu/AnkicardBuildingAutomation/blob/v0.2.0/docs/windows.md).
