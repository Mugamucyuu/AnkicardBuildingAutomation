# Ankicard 0.4.0 — Reliable exit, resumable generation and two-phase writing

## 中文

- 修复右上角退出键造成窗口未响应的问题：退出检查、确认、保存和更新交接都在后台处理，重复点击不会开启多个退出流程。
- 有生成或导入任务时提醒；取消退出继续工作，确认退出先保存。未保存的提示词编辑仍会单独提醒。
- 中途退出后，重新打开自动进入任务页并显示「继续生成」。保留已完成词卡、原批次提示词和标签快照，复用已保存的检索、内容、排版和标签复核阶段。
- API key 仍只保存在内存中，重启后需重新填写再继续。尚未返回或未保存的模型请求可能已计费，恢复时可能需要再次调用；不会自动启动付费任务。
- 导入中断后按原 run ID 核对 Anki，避免盲目重复导入。
- 包含 v0.3.0 之后的全部生成改进：稳定的请求前缀、携带完整草稿的修正流程、内容撰写与排版分离、排版内容保护，以及三版费用和失败率对比文档。

下载 **`Ankicard-0.4.0-windows-x64-Setup.exe`**。安装程序会识别同一 Windows 用户的原安装目录，保留设置、提示词、个人词库、任务与媒体；无需卸载旧版，也无需 Python 或 localhost 配置。

**v0.3.0 升级注意**：原版 v0.3.0 的自动更新检测和下载安装包仍可用，但安装前关闭应用也经过旧版的退出代码，可能卡住。遇到该情况请结束旧版应用进程，再运行 v0.4.0 Setup 完成一次覆盖升级。旧版进程中的关闭缺陷不能仅靠发布新版安装包修复。v0.4.0 已修复这条关闭与更新交接路径。

支持 Windows 10 1809+ / Windows 11 x64。安装包包含 Python 与微软离线 WebView2 安装组件，当前应用和安装包未签名。真实生成仍需要模型密钥和额度，导入需要 Anki 与 AnkiConnect。

## English

- Fix the native title-bar close deadlock. Inspect drafts, confirm active work, save state and prepare update handoff off the UI thread; coalesce repeated close clicks.
- Save interrupted batches as paused. On restart, show Activity and explicit Resume generation controls. Reuse completed research/content/formatting/tag-review stages and keep completed cards and immutable batch snapshots.
- Require credentials again after restart; never resume paid work automatically. Unfinished unsaved requests may need repeating and may already have been billed. Preserve run-ID reconciliation for interrupted Anki imports.
- Include all post-0.3.0 request-prefix, draft repair and two-phase writing/formatting improvements, protected-content checks and comparative profiling documentation.

Run Setup to upgrade in place. The fixed application ID retains the previous install directory; user data lives separately and survives upgrade and uninstall.

**Original 0.3.0 caveat:** discovery and verified download are available, but its old native close code can stall before installation. End the stalled old app and run 0.4.0 Setup once. A newly published installer cannot retroactively patch an already installed process. The shutdown/update handoff is fixed in 0.4.0.

Validation includes 204 Python tests; real Edge theme/editor workflows; real WebView2 close cancellation, saved shutdown and three-language UI resume; frozen desktop checks without Python on PATH; and actual 0.3.0-to-0.4.0 Setup/helper/relaunch, previous-directory detection, downgrade rejection and uninstall with retained settings, custom prompts and jobs. The helper test uses a local release fixture; it does not establish that the unmodified 0.3.0 native close path works. See [update verification](../updates.md).
