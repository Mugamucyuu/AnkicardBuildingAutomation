# Ankicard 0.3.0 — Themes, prompt editing and in-app updates

## 中文

- **版本管理**：设置页显示当前/最新版本并支持一键更新。下载校验后备份数据、原位安装并重启，安装包也会自动识别旧安装目录。
- **数据衔接**：0.2.x 数据先备份再迁移；提示词、设置、词库与任务保留。正在执行生成或导入时不会安装更新，未保存的编辑会提醒。

- **四套配色**：纸白墨蓝、暖纸苔绿、雾紫、石墨夜色；在「设置」中选择配色，并独立选择浅色、深色或跟随系统，保存后下次打开沿用。
- **离线字体**：随应用打包字体，优化中文与英文字体搭配；暖纸苔绿使用宋体/衬线标题。
- **直接编辑提示词**：支持正常文本输入、复制粘贴、撤销/重做和 Ctrl+S；也可以新建提示词或导入 UTF-8 TXT/MD 文件。
- **保存与启用**：保存会保留旧版本，点击「用于新任务」才启用。内置提示词编辑后另存为自定义版本；自定义版本可删除。
- **任务记录保留**：删除正在使用的版本会恢复内置版本。已有及进行中的任务仍使用自己的提示词快照。
- 保留此前的 Anki 连接成功后清除相关错误提示的修复。

下载 `Ankicard-0.3.0-windows-x64-Setup.exe`，关闭旧版后运行安装包升级。
0.2.0 首次升级仍需运行新版安装包，之后可使用应用内更新。
任务、提示词和用户设置保留。无需自行安装 Python 或配置 localhost。
支持 Windows 10 1809+ / Windows 11 x64；安装包包含离线 WebView2 安装组件。
当前安装包未签名，Windows 可能提示未知发布者。
真实生成仍需要模型密钥与额度；导入仍需要 Anki 和 AnkiConnect。

## English

- Current/latest version display, optional startup checks and one-click Windows updates with verified downloads, local backups, in-place install and native relaunch.
- Setup detects the previous directory and rejects detected downgrades; additive data migrations preserve 0.2.x settings, prompts, vocabulary and jobs.

- Four coordinated palettes with separate light/dark/system appearance and bundled fonts for offline use.
- Direct prompt editing with native text operations, new documents, TXT/MD import and Ctrl/Cmd+S.
- Immutable saved versions, explicit activation for new tasks, deletion of custom versions, default restoration and unsaved-draft warnings.
- Existing jobs keep their prompt snapshots after edits/deletion. Retains the latest local Anki connection/tag-notice recovery fix.

Close the app and run Setup to upgrade. Preferences, prompts and generated jobs are retained.
Windows 10 1809+ / Windows 11 x64. Python and the offline WebView2 installer are included.
The application/installer are unsigned. Model credentials/credit and AnkiConnect requirements remain.

Validation: 182 Python tests, real Edge workflow checks, installed-wheel resources/API checks,
frozen WebView2 smoke checks, and 0.2.0-to-0.3.0 update/helper/relaunch, old-directory detection,
downgrade rejection and uninstall with retained data. Update network responses use local release
fixtures in tests; the actual installer and native restarted application are exercised.
The WebView2-absent branch uses Microsoft's documented offline installation flow; it has
not been separately exercised in a clean VM without WebView2.
